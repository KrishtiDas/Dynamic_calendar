# ⏰ Dynamic Clock & Calendar

A responsive and interactive **Digital Clock & Calendar Web Application** built using **HTML, CSS and JavaScript**.

The project provides a live digital clock, dynamic monthly calendar, date selection, theme switching, 12/24-hour time format, and world clocks for different time zones — all within a clean and responsive interface.

---

## 🌐 Live Features

The application includes:

- ⏰ Real-time digital clock
- 📅 Dynamic calendar
- ◀️ Previous month navigation
- ▶️ Next month navigation
- 📌 Today button
- 🖱️ Selectable calendar dates
- 🌙 Dark Mode
- ☀️ Light Mode
- 🕐 12-hour / 24-hour time format
- 🌍 World clocks
- 🇮🇳 Kolkata
- 🇬🇧 London
- 🇺🇸 New York
- 🇯🇵 Tokyo
- 💾 Theme preference using Local Storage
- ✨ Smooth page-load animations
- 📱 Responsive design for desktop, tablet and mobile
